# 🌠 별무리 개척기

방치형 RPG (웹 · PWA). 전투 방식, 생활 스킬, 특수 옵션 구조는 같은 장르를 참고해 새로 설계했습니다. 수치·이름·구성은 모두 이 게임용입니다.

## 실행
```
python -m http.server 8095 -d www
```
브라우저에서 http://localhost:8095

## 핵심 구조
- **스킬 15종 (Lv 1~100)**
  - 전투: 공격 · 힘 · 방어 · 원거리 · 마법
  - 신성 (뼈 묻기 → 기도 해금) · 도둑질 (성공률 = 레벨 + 도둑질 성공률)
  - 생활: 벌목 · 채광 · 낚시 · 대장 · 공예 · 요리 · 연금술 · 마법 공예
- **최고 Lv 200 · 지역 44곳 (몬스터 최고 Lv 230) · 장비 21단계** (청동 ~ 무한) · 장비 등급 8단계 (일반 ~ 유물)
- **스탯 7종만:** 공격 · 힘 · 방어 · 원거리 · 마법 · 생명력 흡수 · 피해 감소
- **전투 공식** (최종 스탯 = 레벨 + 장비)
  - 최대 피해: 근접 (공격 + 힘) × 0.85 / 원거리 × 0.85 / 마법 × 0.70 × 주문 배율
  - 몬스터 방어 × 0.3만큼 최대 피해가 깎이고, 내 공격은 항상 맞음
  - 적 명중률 = 적 공격 ÷ (적 공격 + 내 방어 × 0.43)
  - 맞으면 적 힘 × 0.42~0.58, 방어 효율만큼 줄고 피해 감소 %를 한 번 더 뺌
  - 최대 체력 = 100 + 방어 레벨마다 5 (50 이후 조금씩 더)
  - 약점 방식으로 때리면 적 방어 절반
- **편의:** 배속 x1~x32 · 몬스터를 누르면 전리품 표 · 전투력 · 올리면 좋은 스탯 추천 (실제 전투 / 전투력)
- **기도 · 펫:** 위 스탯만 % 또는 흡수 · 피해 감소로 올림 (생활 펫은 채집 · 제작 보너스)
- **진행:** 오프라인 최대 12시간 · 자동 저장 · 세이브 코드 내보내기/불러오기
- **보너스 (%):** 공격 · 힘 · 방어 · 원거리 · 마법 · 드롭률 · 채집 속도 · 생산 속도 · 제작 속도 · 틱당 체력 · 도둑질 성공률 · 보스 피해 · 생활 경험치
