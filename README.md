# 🌠 별무리 개척기

방치형 RPG (웹 · PWA). 전투 방식, 생활 스킬, 특수 옵션 구조는 같은 장르를 참고해 새로 설계했습니다. 수치·이름·구성은 모두 이 게임용입니다.

## 실행
```
python -m http.server 8095 -d www
```
브라우저에서 http://localhost:8095

## 핵심 구조
- **스킬 13종 (Lv 1~100)**
  - 전투: 공격 · 힘 · 방어 · 체력 · 원거리 · 마법
  - 신성 (뼈 묻기 → 기도 해금)
  - 생활: 벌목 · 채광 · 낚시 · 대장 · 공예 · 요리
- **전투 공식**
  - 굴림 = (레벨 + 10) × (장비 보너스 + 50)
  - 명중 = 내 굴림 ÷ (내 굴림 + 적 방어 굴림)
  - 최대 피해 = 1 + (위력 레벨 + 8) × (공격력 + 40) ÷ 200
  - 맞으면 1 ~ 최대 피해
  - 플레이어와 몬스터가 각자 공격 주기마다 공격
  - 근접 · 원거리 · 마법 상성 (몬스터마다 약점)
- **장비**
  - 8단계, 수치 고정, 강화 · 큐브 없음
  - 부위마다 고정 ★ 특수 옵션: 무기 치명타 · 방패 피해 감소 · 머리 명중 · 상의 최대 체력 · 하의 회피 · 장갑 공격 속도 · 신발 드롭률 · 목걸이 경험치 · 반지 흡혈 · 망토 피해 반사
- **신성:** 기도 13종, 1개만 켬, 각자 특수 옵션 (보호 기도 포함)
- **펫:** 14종 (생활 스킬 6 · 지역 보스 8), 펫마다 특수 옵션
- **진행:** 오프라인 최대 12시간 · 자동 저장 · 세이브 코드 내보내기/불러오기
